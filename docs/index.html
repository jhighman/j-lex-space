The question

Before we ask whether an intelligent system can determine what is true, a more primitive question: why did it believe the claim deserved consideration in the first place?

Alexicon is an independent working group for the epistemics of governed intelligence. Independent means what it says: no institution, no sponsor, no employer. The work answers to the record and to whoever is willing to check it.

Most work on machine trustworthiness concentrates on the exit — whether a conclusion is warranted. We think a boundary exists earlier and is almost entirely ungoverned: the point at which a claim is admitted to consideration at all.

Two boundaries

Trust is the discipline of preventing inference from becoming evidence. The Sentinel Principle

At the entrance

Plausibility is not trustworthiness.

At the exit

Inference is not evidence.

A statement that arrives compatible with the prior model, from a source with status, in familiar language, meets no resistance — and is therefore never examined. That is not a description of a true claim. It is a description of a claim nobody will look at, which is why the entrance needs governing as much as the exit does.

The instrument

This is not a product. Not a production engine, not a database, not a library to depend on, and emphatically not a truth detector. It is a reference instrument: it exists so that structural claims can be exposed, measured, and falsified by anyone who wants to try. Its database is in memory and evaporates when the process ends — which disqualifies it for any other use, and is exactly right for this one.

The code is public rather than a specification alone, and that follows from the framework's own discipline. Something claiming to prevent inference from becoming evidence cannot ask to be taken on trust. Provably blind to status means nothing unless you can run the file.

git clone https://github.com/jhighman/j-lex-space
cd j-lex-space

python3 framework/demo.py        # the ideas, running
python3 experiments/check.py     # every boundary, checked
python3 experiments/forgery.py   # attack the ledger directly

No dependencies. Standard library only. Written to be read top to bottom. The guards fail loudly and exit non-zero — if you find a route past one, that is the most valuable contribution available here.

What failed

A project about the discipline of not promoting inference to evidence cannot keep a scoreboard that flatters itself. The negative results are published first and at the same length as the successes.

The value layer does not work

The framework's third level asks what commitments made an argumentative step feel warranted before the evidence arrived. It was tested against a discrimination control: genuine argumentative steps in one arm, construction-identical claim pairs that had never formed an argument in the other. A working layer finds materially more conflict in the real arm.

The fourth was the strongest test available, run on the example most likely to favour the theory. Conflict was identified in 85.7% of genuine steps and 85.7% of shuffled pairs — twenty-eight of each, a gap of exactly zero. The model did not go quiet under longer context; it answered almost everywhere. What collapsed was discrimination. More context did not ground the question. It gave the judge more to invent with.

Two conclusions, both load-bearing. Closure constructs the object; it does not guarantee the text contains the answer the instrument wants. And plausibility could not serve as evidence — which means the entrance boundary was discovered empirically, in a failed experiment, before it was ever named. The framework's worst result is the clearest evidence for its newest claim.

There is no value layer in the repository. Not because it is unfinished, but because it does not currently work, and shipping a non-functioning epistemic layer as though it functioned would be the exact failure this project exists to name.

Found, versus built

A sentinel was built from the master axiom alone and then probed for commitments it had never been given. It rediscovered four. It never invented an entrance boundary — that absence is the finding, and the reason these columns stay separated permanently.

The full findings also record every boundary the code failed to hold before it held — three holes found the first time the ledger was attacked directly, a test that believed a docstring, a fact about the past answered from the present, and a revocation that revoked nothing — with dates, and a plain account of what the instrument cannot establish.

In preparation

The Geometry of Trust

From Plausibility to Evidence: Structural Invariants for Governed Intelligence. Alexandra Krížová, author; Jeff Highman, peer reviewer. Stage: proposed.

Its two refutation conditions were written before its argument, and both are implemented as running checks rather than defended as positions. Read the question and what would refute it.

The framework it builds on is Architecture of Contextual Judgment: Governed Epistemic Transitions (Krížová, first edition 2026).

Claims of the form “the system is mathematically prevented” are not made here. Constructors, schemas, roles and append-only structures buy structural unrepresentability — a state the system cannot be in — and not a proof. That is already an extraordinarily strong claim, and it is one we can demonstrate.
