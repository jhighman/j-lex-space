# social

Material for promoting this research on whatever channel either author
has. One folder per increment, named by date and subject, holding:

- `article.md` — what this increment is, against the last one, written
  to be read by someone who was not here. The long form; cut it down for
  the channel.
- `post.md` — short forms ready to paste, with the tags, and a log of
  where and when each was posted.
- `article.html` — the article and the short forms as one page, no
  scripts and nothing fetched, so it can be opened from the folder or
  put on any channel as it stands. Written by hand; keep it in step
  with `article.md` when that changes.
- whatever a reader needs to run the thing being talked about: here, a
  standalone build of the Visualizer Demo and the score it plays.

Either author may use anything in this folder on any channel. Jeff posts
on X (`@jeffhighman`, tagging `@aLexKriz83`, `@DevCoBand`, `#alexicon`);
Lex has no paid X account and is free to do something different.
Deciding *when* to post an increment is an issue on this repository, like
any other correspondence between the authors.

## Where the takes are

Rendered takes are MP4s of 80–100 MB and are not committed. They live in
`visualizer-demo/takes/`, which git ignores, on the machine that recorded
them, and go to a channel as an upload. Each post folder names the take
it was made from.
