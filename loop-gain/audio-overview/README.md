# The audio overview, and what to do with it

On 2026-10-28 the staging folder for this piece (the paper, the thesis,
the bench READMEs, the proofs, the issue threads) was given to a Google
Notebook, which generated a 22:40 two-host audio overview titled *How
Algorithmic Feedback Loops Trap Us*. The audio file is not tracked here;
it is 44 MB and a derived artifact. What is kept:

- `transcript.md` — a local transcription (Whisper `small`, no network),
  timestamped by segment, so the review can be checked line by line.
- `review.md` — the overview against the record: what it got right, what
  it invented (a research community, gigabytes of logs, a definition of
  agency), where it slid from "in the model" to "in your mind", what it
  left out (the failed H1, Lex's role), and the one passage that is false
  (the reverse arrow as "proven").
- `corrections.md` — a plain-sentence source to add to the Notebook
  before regenerating, stating the facts the overview needs.

The overview is kept as the sketch it was. The video script in
`../video/script.md` replaces it for the audience it was meant for. The
usual caveat: the same process that built the piece reviewed the audio
about it.
