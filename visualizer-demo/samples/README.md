# Source songs

Tracks to play the demo with.

| file | |
|---|---|
| `Editions.mp3` | 5:25, all in major keys |
| `Again it's Christmas time.mp3` | 3:40, moving through A♭ major, F minor and C minor and back |

Run `npm run dev`, open the page, and drop a song on it. Press `V` to
record a take; it saves an MP4 when the song ends.
