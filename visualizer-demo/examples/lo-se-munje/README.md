# Lo Se Munje · eight takes

Eight recorded takes of the same song, *Lo Se Munje*, each drawn by a
different lens, made between 12 and 16 October 2026 and brought into the
workbench on 20 October as examples for the Phase Transition review
(issue #9). Each is 1:25. A frame from forty seconds in sits beside each
take.

| take | lens on air at 0:40 | what the frame shows |
|---|---|---|
| `lo-se-munje-1.mp4` | Atlas | the song's timeline as a ring of parts, Bridson's growth filling the body inside it |
| `lo-se-munje-2.mp4` | Aizawa | a shape that never leaves and never repeats, traced by motes, with the spectrum as a ring of spikes |
| `lo-se-munje-3.mp4` | Loft | a body written as spines and fans; the motes gather into a figure that stands |
| `lo-se-munje-4.mp4` | Guard | particles cross a threshold and are counted; the body decides what crosses |
| `lo-se-munje-5.mp4` | Schema | a wireframe kept by generative rules, with its signal path, emotion emitter and philosophy emitter drawn as panels |
| `lo-se-munje-6.mp4` | Schema | the same, with an ignorance emitter: words not read, language not read, the camera never opened |
| `lo-se-munje-7.mp4` | Hopf | two families of opposite-handed rings, each lit where the music is |
| `lo-se-munje-8.mp4` | Sigil | an alphabet of fifteen glyphs, one per feature of the signal, laid out as a line |

Each take carries its captions: the API calls that drove it, top left,
and the lens's own label and note, top right, so a viewer can see what was
asked of the body and when.

## Provenance, stated plainly

- **The lenses.** Six of these eight (Aizawa, Loft, Guard, Schema, Hopf,
  Sigil) are not in this repository's `src/lenses/`, which holds the
  fourteen the README describes, and they are not in its history. The
  takes were made with a build of the visualizer that is not on the
  machine these files came from. Until that source is found or brought
  in, the takes are examples of what the instrument has drawn, not
  takes that can be re-run from this repository. The two that use Atlas
  can.
- **The files.** Transcoded from the originals (1920×1080 at 60 fps,
  about 15 Mb/s, 85–171 MB each) to 1080p at 30 fps, H.264 CRF 23, AAC
  160 kb/s, so each sits under GitHub's file limits. The originals stay
  on Jeff's machine. Nothing else was changed.
- **The song.** *Lo Se Munje* is Jeff's. How it was made is part of the
  disclosure the programme asks for and is to be stated with the
  submission, not assumed here.
- **The caveat.** The same process built the instrument, recorded the
  takes and wrote this note.
